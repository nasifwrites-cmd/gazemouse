# GazeMouse (আই মুভমেন্ট মাউস ও সাউন্ড স্ন্যাপ ক্লিক)

অন-ডিভাইস সম্পূর্ণ লোকাল আই-ট্র্যাকিং মাউস কন্ট্রোলার এবং সাউন্ড স্ন্যাপ ক্লিক ডিটেক্টর অ্যান্ড্রয়েড অ্যাপ। এখানে কোনো ক্লাউড সার্ভার বা এআই নেই — সব প্রসেসিং ফোনের ক্যামেরায় লোকালি সম্পন্ন হয় এবং লোকাল স্টোরেজে সেভ হয়।

---

## 🌟 মূল ফিচারসমূহ (Key Features)

1. **আই মুভমেন্ট মাউস (Eye Gaze Mouse Tracker):**
   - ফোনের ফ্রন্ট ক্যামেরা ব্যবহার করে সরাসরি চোখের পিউপিল মুভমেন্ট ট্র্যাক করে।
   - স্ক্রিনের উপর স্মুথ ভার্চুয়াল কার্সার গ্লাইড করে।
   - ক্যামেরা প্রিভিউতে পিউপিল পজিশন ও আই বক্স লাইভ দেখা যায়।

2. **৯-পয়েন্ট গ্রিড ক্যালিব্রেশন (9-Point Grid Calibration):**
   - স্ক্রিনের ৯টি নির্দিষ্ট গ্রিড পয়েন্টে তাকিয়ে ক্যালিব্রেশন সম্পন্ন করা হয়।
   - ক্যালিব্রেশন ডেটা লোকাল ডেটাবেজে (Room Database) সেভ থাকে, যাতে বারবার করতে না হয়।

3. **সাউন্ড স্ন্যাপ ক্লিক (Audio Snap Click Detector):**
   - মাইক্রোফোন দিয়ে রিয়েল-টাইম অডিও ডেসিবল মনিটর করে।
   - যখনই আঙুলের স্ন্যাপ, তালি বা কোনো আকস্মিক শার্প শব্দ হয় (হঠাৎ ডেসিবল বেড়ে যাওয়া), সেটাকে মাউস ক্লিক হিসেবে ডিটেক্ট করে।
   - যেদিকে তাকিয়ে আছেন, সেখানে ইনস্ট্যান্ট ক্লিক ও হ্যাপটিক ভাইব্রেশন পড়ে।

4. **ইন্টারেক্টিভ প্লেগ্রাউন্ড (Playground):**
   - **টার্গেট পপ গেম:** তাকিয়ে স্ন্যাপ করে বাবল ফাটানো ও স্কোর করা।
   - **ভার্চুয়াল কিপ্যাড:** তাকিয়ে স্ন্যাপ করে নাম্বার টাইপ করা।
   - **আই পেইন্ট ক্যানভাস:** তাকিয়ে স্ন্যাপ করে ড্রয়িং করা।

5. **সম্পূর্ণ লোকাল স্টোরেজ ও এক্সপোর্ট:**
   - ডেটাবেজ ও সেশন লগ সম্পূর্ণ ফোনে লোকালি থাকে।
   - এক ক্লিকে সম্পূর্ণ ডেটা JSON ফাইলে এক্সপোর্ট ও শেয়ার করা যায়।

## 🚀 গিটহাবে পুশ ও GitHub Actions থেকে APK ডাউনলোড

GitHub-এর সিকিউরিটি নিয়মের কারণে কোনো থার্ড-পার্টি অ্যাপকে 'workflow' পারমিশন না দিলে `.github/workflows/` ফোল্ডারে ফাইল পুশ করা ব্লক করে দেয়। তাই পুশ যাতে নির্বিঘ্নে সফল হয়, সেজন্য ওয়ার্কফ্লো ফাইলটি **`ci/build-apk.yml`** ফাইলে সংরক্ষণ করা হয়েছে।

### ধাপ ১: এখন নিরাপদে পুশ করুন
এখন আর কোনো পারমিশন এরর আসবে না। সহজে পুশ হবে।

### ধাপ ২: গিটহাবে অ্যাকশন চালু করার ২টি সহজ উপায়:

#### সহজ উপায় (GitHub Web UI থেকে):
1. গিটহাবে আপনার রিপোজিটরিতে যান।
2. **`ci/build-apk.yml`** ফাইলটি ওপেন করে কোড কপি করুন।
3. **"Add file" > "Create new file"**-এ ক্লিক করে ফাইলের নাম দিন:
   `.github/workflows/build-apk.yml`
4. কপি করা কোড পেস্ট করে **"Commit changes"** করে দিন!

#### অথবা অ্যাপ পারমিশন আপডেট:
GitHub-এর `Settings -> Applications -> Authorized GitHub Apps -> AI Studio`-তে গিয়ে "Workflows" পারমিশন রিবিল্ড/অনুমোদন দিন।

### ধাপ ৩: সামারি থেকে APK ডাউনলোড
1. গিটহাবের **Actions** ট্যাবে যান।
2. **`Build Android APK`** রানের সামারি পেজের **Artifacts** সেকশন থেকে সরাসরি **`GazeMouse-Debug-APK`** ডাউনলোড করে নিন!
